# コロネンゲーム 〜多環芳香族のしんか〜

おなじ分子をくっつけると進化する、スイカゲーム風のブラウザゲームです。
`index.html` をブラウザで開くだけで遊べます（Matter.js とフォントは CDN から読み込み）。

## 進化ルール

```
ベンゼン → ナフタレン ─┬─ アントラセン → テトラセン → ペンタセン ─┐
                      │  （50% ランダム分岐）                       ├→ トリアンギュレン → コロネン → (消滅ボーナス)
                      └─ フェナレン   → ピレン     → ペリレン   ─┘
```

- 直鎖状（ナフタレン・アントラセン・テトラセン・ペンタセン）はフットボール形のあたり判定
- 分岐確率・大きさ・得点は `index.html` 冒頭の `BRANCH_P` / `RADII` / `POINTS` / `EVOLVE` で調整できます
